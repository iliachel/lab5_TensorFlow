# Подробное описание скрипта `election_prediction.py`

## 1. Общая цель скрипта

Этот скрипт представляет собой полный конвейер (pipeline) для решения задачи машинного обучения — предсказания результатов выборов на основе синтетических данных. Он демонстрирует все ключевые этапы, от создания данных до обучения, оценки и развертывания модели. В качестве основной модели используется нейронная сеть (многослойный перцептрон), а для сравнения производительности также обучаются классические модели, такие как Логистическая Регрессия и Случайный Лес.

---

## 2. Пошаговое описание работы скрипта

### Шаг 1: Генерация данных (`generate_data`)

- **Что делает:** Создает два файла с синтетическими данными, если они еще не существуют.
- **`dataIn.txt`**: Этот файл содержит входные данные (признаки). Он представляет собой матрицу, где каждая строка — это один из 12 вопросов анкеты, а каждый столбец — это один из 200 избирателей. Значения в матрице — 0 или 1, имитирующие ответы "нет" или "да".
- **`dataOut.txt`**: Этот файл содержит выходные данные (метки классов). Он представляет собой матрицу, где каждый столбец соответствует избирателю. В матрице два ряда, и она использует кодирование **one-hot**:
    - `[1, 0]` означает, что избиратель проголосовал за "Правящую партию" (класс 0).
    - `[0, 1]` означает, что избиратель проголосовал за "Оппозицию" (класс 1).
- **Воспроизводимость:** Используется `np.random.seed(42)`, чтобы при каждом запуске генерировались одни и те же "случайные" данные. Это важно для того, чтобы можно было воспроизвести результаты обучения.

### Шаг 2: Загрузка и предобработка данных (`load_and_preprocess_data`)

- **Что делает:** Загружает данные из `dataIn.txt` и `dataOut.txt` и приводит их к формату, необходимому для библиотеки `Keras`.
- **Транспонирование:** Изначально данные сохраняются в формате `(признаки, образцы)`. Однако `Keras` ожидает формат `(образцы, признаки)`. Функция проверяет размерность загруженных матриц и, если нужно, **транспонирует** их (меняет строки и столбцы местами).
- **Изменение типа данных:** Целочисленные значения преобразуются в `float32`, стандартный тип данных для вычислений в `TensorFlow/Keras`.

### Шаг 3: Разделение данных (`train_test_split`)

- **Что делает:** Делит весь набор данных на две части:
    - **Обучающая выборка** (`X_train`, `y_train`): 70% данных, на которых модель будет учиться.
    - **Тестовая выборка** (`X_test`, `y_test`): 30% данных, которые модель "не видит" во время обучения. Они используются для объективной оценки ее производительности.
- **Стратификация:** Параметр `stratify` используется для того, чтобы в обучающей и тестовой выборках сохранилось одинаковое соотношение классов (процент голосов за каждую партию), как и в исходном наборе данных. Это особенно важно при несбалансированных классах.

### Шаг 4: Построение нейронной сети (`build_nn_model`)

- **Что делает:** Создает архитектуру нейронной сети с помощью `Keras`.
- **Структура модели:**
    1. **Входной слой:** Принимает на вход вектор из 12 признаков (ответов на вопросы).
    2. **Скрытый слой:** Полносвязный слой (`Dense`) с 16 нейронами. Функция активации **`sigmoid`** (`logsig` в терминологии Matlab) преобразует выход каждого нейрона в значение от 0 до 1. Этот слой извлекает скрытые зависимости в данных.
    3. **Выходной слой:** Полносвязный слой (`Dense`) с 2 нейронами (по одному на каждый класс). Функция активации **`softmax`** преобразует выходы в массив вероятностей, сумма которых равна 1. Например, выход `[0.2, 0.8]` означает, что модель на 80% уверена, что избиратель проголосовал за "Оппозицию".
- **Компиляция:** Модель "собирается" с указанием:
    - **Оптимизатор `adam`**: Эффективный алгоритм, который подбирает веса нейронов, чтобы минимизировать ошибку.
    - **Функция потерь `categorical_crossentropy`**: Мера ошибки, которую модель пытается минимизировать. Подходит для задач классификации с one-hot кодированием.
    - **Метрика `accuracy`**: Точность (доля правильных ответов), которая отслеживается в процессе обучения.

### Шаг 5: Обучение модели (`train_model`)

- **Что делает:** Запускает процесс обучения нейронной сети на обучающих данных.
- **Эпохи и батчи:** Обучение идет итеративно (`epochs`). На каждой эпохе модель просматривает все данные из обучающей выборки. Данные подаются небольшими порциями (`batch_size`), что делает обучение более стабильным.
- **Ранняя остановка (`EarlyStopping`):** Это мощный инструмент для предотвращения **переобучения**. Скрипт следит за ошибкой на валидационной (тестовой) выборке (`val_loss`). Если ошибка не уменьшается в течение `patience=10` эпох, обучение автоматически прекращается. При этом модель возвращается к состоянию с наилучшими весами, которые были достигнуты до начала "ухудшения".

### Шаг 6: Оценка производительности (`evaluate_and_report`)

- **Что делает:** Всесторонне оценивает качество обученной модели на тестовых данных.
- **Ключевые метрики:**
    - **Accuracy (Точность):** Общий процент правильных предсказаний.
    - **Classification Report:** Более детальный отчет, показывающий `precision` (точность), `recall` (полнота) и `f1-score` для каждого класса. Это помогает понять, какой класс модель предсказывает лучше, а какой — хуже.
    - **Confusion Matrix (Матрица ошибок):** Таблица, которая показывает, сколько раз модель правильно предсказала каждый класс и где именно она ошиблась (например, сколько избирателей "Оппозиции" она ошибочно отнесла к "Правящей партии").
    - **ROC-AUC:** Площадь под ROC-кривой. Эта метрика показывает, насколько хорошо модель способна разделять классы. Значение, близкое к 1.0, говорит об отличном качестве модели; значение около 0.5 — о том, что модель работает не лучше случайного угадывания.

### Шаг 7: Визуализация результатов (`visualize_results`)

- **Что делает:** Создает и сохраняет в папку `plots` три вида графиков для наглядного анализа.
    1. **Кривые обучения:** Показывают, как менялись ошибка (`loss`) и точность (`accuracy`) на обучающей и валидационной выборках от эпохи к эпохе. По этим графикам можно диагностировать переобучение или недообучение.
    2. **Тепловая карта матрицы ошибок:** Визуальное представление матрицы ошибок. Цветом выделены ячейки с наибольшими значениями, что позволяет быстро увидеть, какие ошибки модель совершает чаще всего.
    3. **PCA-проекция:** Метод главных компонент (PCA) используется для снижения размерности данных с 12 до 2. Это позволяет визуализировать тестовые данные на 2D-графике. Точки раскрашиваются в зависимости от их реального класса. В идеале, точки разных цветов должны образовывать два хорошо различимых кластера.

### Шаг 8: Сравнение с классическими моделями (`compare_with_classical_models`)

- **Что делает:** Обучает на тех же данных две стандартные модели машинного обучения и выводит их точность.
    - **Логистическая регрессия:** Простая, но эффективная линейная модель.
    - **Случайный лес:** Мощный ансамблевый метод, который часто показывает высокую точность "из коробки".
- **Цель:** Это позволяет сравнить производительность сложной нейросетевой модели с более простыми и быстрыми альтернативами и понять, оправдано ли использование нейросети в данной задаче.

### Шаг 9: Сохранение модели (`model.save`)

- **Что делает:** Сохраняет всю обученную модель (архитектуру, веса, конфигурацию оптимизатора) в один файл `mlp_elections_model.h5`.
- **Польза:** Этот файл можно будет в дальнейшем загрузить в другом скрипте для получения предсказаний на новых данных, без необходимости заново обучать модель.

---
Этот конвейер является хорошим примером стандартного подхода к решению задач классификации с помощью нейронных сетей.
